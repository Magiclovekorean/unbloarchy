# Αναστολή λειτουργίας του συστήματος

Το Unbloarchy ενεργοποιεί την αναστολή και την αδρανοποίηση από προεπιλογή, αλλά αν αντιμετωπίζετε προβλήματα με κάποια από τις δύο στο μηχάνημά σας, μπορείτε να τις απενεργοποιήσετε.

Στα μηχανήματα NVIDIA GB10, όπως το DGX Spark και το ASUS Ascent GX10, η αναστολή και η αδρανοποίηση είναι απενεργοποιημένες, όπως και στο DGX OS της NVIDIA, επειδή δεν έχει αποδειχθεί ακόμη ότι η αναστολή λειτουργίας δουλεύει σε αυτό το hardware. Η εναλλαγή αναστολής και η ρύθμιση αδρανοποίησης δεν ισχύουν εκεί. Για να ενεργοποιήσετε ξανά την αναστολή λειτουργίας, αφαιρέστε το `/etc/systemd/sleep.conf.d/unbloarchy-sleep-disabled.conf` με `sudo rm`· τότε η Αναστολή επιστρέφει στο μενού και η αδρανοποίηση μπορεί να ρυθμιστεί όπως στα άλλα μηχανήματα. Η εκτέλεση του `sudo unbloarchy apply hardware --install-user "$USER"` επαναφέρει το αρχείο.

### Προφίλ ενέργειας

Σε φορητό υπολογιστή, το Unbloarchy θυμάται το προφίλ ενέργειάς σας ξεχωριστά για όταν είναι συνδεδεμένος στο ρεύμα και για όταν λειτουργεί με μπαταρία, και εναλλάσσεται μεταξύ των δύο καθώς συνδέετε και αποσυνδέετε το καλώδιο. Από προεπιλογή, αυτό σημαίνει performance στην τροφοδοσία AC και balanced στην μπαταρία.

Μπορείτε να δείτε τι προσφέρει το μηχάνημά σας με το `unbloarchy powerprofiles list` και να ορίσετε αυτό που θέλετε για την κατάσταση στην οποία βρίσκεστε αυτή τη στιγμή με το `unbloarchy powerprofiles set autodetect power-saver`. Για να ορίσετε την άλλη κατάσταση χωρίς να αποσυνδέσετε τίποτα, ονομάστε την απευθείας: `unbloarchy powerprofiles set battery power-saver`. Ό,τι επιλέξετε είναι αυτό που θα έχετε ξανά την επόμενη φορά που θα βρεθείτε σε αυτή την κατάσταση.

### Εναλλαγή αναστολής

Εναλλάσσετε την αναστολή εκτελώντας `unbloarchy toggle suspend` από το τερματικό. Αυτό απλώς εμφανίζει/κρύβει την επιλογή στο _System_ (ή `Super + Esc`) και έπειτα μπορείτε να δείτε αν δουλεύει σταθερά στο σύστημά σας. Αν όχι, μπορείτε να την κρύψετε ξανά με την ίδια εντολή.

### Εναλλαγή αδρανοποίησης

Ρυθμίζετε την αδρανοποίηση εκτελώντας `unbloarchy hibernation setup` από το τερματικό. Η αδρανοποίηση δημιουργεί έναν υποτόμο /swap στη μονάδα εκκίνησής σας, με μέγεθος όσο η φυσική σας μνήμη RAM, οπότε βεβαιωθείτε ότι έχετε αρκετό χώρο στη διάθεσή σας. Σε ένα μηχάνημα 32GB, θα χρειάζεστε πάντα 32GB+ ελεύθερα για αυτόν τον τόμο. Η αδρανοποίηση απαιτεί επίσης τον προεπιλεγμένο bootloader Limine.

Αφού ρυθμιστεί, θα δείτε την επιλογή αδρανοποίησης στο _System_ (ή `Super + Esc`) και έπειτα μπορείτε να δείτε αν δουλεύει σταθερά στο σύστημά σας. Αν όχι, μπορείτε να την αφαιρέσετε ξανά εκτελώντας `unbloarchy hibernation remove`.
