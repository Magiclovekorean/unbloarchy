# עדכונים

Unbloarchy והחבילות שלך נשמרים מעודכנים דרך _Update > Unbloarchy_ בתפריט Unbloarchy (`Super + Space`).

Unbloarchy עצמה מותקנת כחבילות pacman רגילות מתוך [מאגר החבילות של Unbloarchy](https://github.com/omacom-io/omarchy-pkgs), כך שעדכון מתקין את [הגרסה האחרונה של Unbloarchy](https://github.com/omacom/omarchy/releases), מריץ את כל המיגרציות הממתינות כדי לסנכרן את המערכת שלך עם הגרסה האחרונה, ומעדכן את כל חבילות המערכת מתוך [מראת Arch של Unbloarchy](https://github.com/omacom-io/omarchy-mirror) ו-[AUR](https://aur.archlinux.org/) (אם התקנת חבילות AUR כלשהן).

כשמתפרסמות גרסאות חדשות, יופיע סמל של חץ מעגלי מימין לשעון שלך. לחץ עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Unbloarchy מתעדכנת לאורך ארבעה ערוצים: stable, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ stable, שעוקב אחר [הגרסאות הרשמיות](https://github.com/omacom/omarchy/releases/), וגם אחר [מראת Arch היציבה של Unbloarchy](https://github.com/omacom-io/omarchy-mirror) שרצה חודש אחד מאחורי הגרסה האחרונה, כדי שנוכל לתפוס כל חוסר תאימות חדש שדורש שינויי תצורה לפני שהוא גורם בעיות לאנשים.

אבל אם תרצה לעזור לזהות את הבעיות הפוטנציאליות האלה, תוכל לרוץ על ערוץ edge. זה ישמור את חבילות Unbloarchy שלך מעודכנות לפי בניית הפיתוח האחרונות, ויאפשר לך להתעדכן לחבילות Arch האחרונות ברגע שהן זמינות. כדאי לעשות זאת רק אם אתה מנוסה ב-Linux, ויודע איך לשחזר מערכת שיש בה בעיות.

לפני כל גרסה ראשית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתה מעוניין לעזור בליטוש הסופי, בוא לבלות ב-#unbloarchy-release-candidates ב-Discord.

לבסוף, יש את ערוץ dev, שמקשר את Unbloarchy ישירות ל-checkout של git של קוד המקור בתוך `~/unbloarchy`, בשילוב עם חבילות edge. כדאי להשתמש בערוץ הזה רק אם אתה משתמש Linux מנוסה, עובד ישירות על Unbloarchy, ומוכן לסבול שבר.

תוכל לעבור בין ערוצים באמצעות _Update > Channel_ מתפריט Unbloarchy (או `unbloarchy-channel-set` במסוף).

### החלפת קרנלים

Unbloarchy מאתחלת עם קרנל `linux-omarchy` משלה, אבל תוכל לשמור אחרים מותקנים לצידה, כמו קרנל `linux` הסטנדרטי של Arch או בנייה ניסיונית שאתה בודק. כשיש יותר מאחד, _Update > Kernel_ בתפריט Unbloarchy מפרט אותם עם סימן וי ליד זה שמאתחל כברירת מחדל. בחר אחר, הזן את הסיסמה שלך פעם אחת, והוא יאתחל לאחר ההפעלה מחדש הבאה. הקרנלים האחרים נשארים בתפריט האתחול, כך שעדיין תוכל לבחור אחד ידנית אם ברירת המחדל החדשה עושה לך בעיות. במסוף, זה `unbloarchy-kernel` כדי לראות את ברירת המחדל הנוכחית, `unbloarchy-kernel list` למה שמותקן, ו-`unbloarchy-kernel set <kernel>` כדי להחליף.

### עדכוני קושחה

החבילות שלך הן לא הדבר היחיד שמתיישן. מחשבים ניידים וציוד היקפי רבים מספקים קושחת BIOS, SSD ועגינה דרך Linux Vendor Firmware Service, ו-_Update > Firmware_ בתפריט Unbloarchy יביא ויתקין את כל מה שממתין לחומרה שלך. הוא מתקין את `fwupd` בפעם הראשונה שאתה מריץ אותו. הרבה קושחה ניתן לכתוב רק במהלך הפעלה מחדש, אז אל תופתע אם תתבקש לעשות אחת.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתה כבר מכיר את Arch, אתה עלול להתפתות פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמך, אבל אם תעשה זאת, תפספס את ה-snapshot, המיגרציות ועדכוני התצורה ש-Unbloarchy מריצה יחד עם חבילות חדשות. לכן Unbloarchy למעשה תעצור שדרוג מערכת ישיר ותפנה אותך ל-`unbloarchy update` במקום זאת. (אם אתה באמת יודע מה אתה עושה, המגן יגיד לך איך לעקוף אותו עבור טרנזקציה בודדת.)

### חזרה לאחור מעדכונים גרועים

אם אי פעם תהיה לך בעיה לאחר ביצוע עדכון, תוכל להחזיר את המערכת שלך ל-snapshot שצולם לפני העדכון. פשוט הפעל מחדש ובחר בתפריט טעינת האתחול את ה-snapshot מלפני שהתחלת את העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלך הושחתו, תוכל גם לבצע התקנה מחדש של Unbloarchy באמצעות `unbloarchy reinstall` במסוף. זה יתקין מחדש את כל חבילות ברירת המחדל של Unbloarchy, יעביר אותך ל-stable ויוריד גרסה של כל חבילה שחדשה מדי, ויאפס את כל קבצי התצורה. שים לב שכל שינויי תצורת המשתמש שלך לברירות המחדל של Unbloarchy יידרסו בעת ביצוע פעולה זו!
